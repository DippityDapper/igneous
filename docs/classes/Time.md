# Time

**Header:** `include/igneous/engine/Time.hpp`  
**Namespace:** `Engine`

## Overview

Static timing state updated each frame by the engine.

## Members

| Member | Description |
|--------|-------------|
| `lastTick` | Previous frame tick (ms) |
| `currentTick` | Current frame tick (ms) |
| `deltaTime` | Seconds elapsed since last frame |
