# audio

**Target:** `example_audio`  
**Feature:** AudioStream, ResourceManager::LoadSound

Demonstrates one-shot UI sounds and looping footstep samples while moving.

## Assets

- `assets/sounds/button/button1.wav` … `button5.wav`
- `assets/sounds/footsteps/concrete1.wav` … `concrete4.wav`
- `assets/sounds/footsteps/dirt1.wav` … `dirt4.wav`

## Controls

| Input | Action |
|-------|--------|
| **ImGui button** | Play next button click sound |
| **Hold WASD** | Play footstep samples on an interval |
| **Escape** | Quit |
