# z_index

**Target:** `example_z_index`  
**Feature:** ResourceManager sprite ordering

Three overlapping sprites use different z-index values so draw order is visible.

## Assets

- `assets/sprite-sheets/colonist_green_spritesheet.png` (back, z=0)
- `assets/sprites/crew_1.png` (middle, z=1)
- `assets/sprite-sheets/colonist_pink_spritesheet.png` (front, z=2)
