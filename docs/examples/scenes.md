# scenes

**Target:** `example_scenes`  
**Feature:** Scene, SceneManager, SceneRoot load/unload

Two scenes (menu and game) are registered at startup. Switch between them with the keyboard.

## Assets

- `assets/sprites/crew_1.png` (game scene)

## Controls

| Scene | Input | Action |
|-------|-------|--------|
| Menu | **Enter** | Load game scene |
| Game | **Backspace** | Return to menu |
| Any | **Escape** | Quit |
