# input_gamepad

**Target:** `example_input_gamepad`  
**Feature:** Gamepad buttons, raw and semantic stick axes, rumble

Shows connected controllers, active button state, raw SDL stick values, semantic directional axis halves, and rumble controls for motors and triggers.

## Assets

None.

## Controls

- **Gamepad** — buttons and sticks
- **UI sliders + Rumble buttons** — test `RumbleGamepad` and `RumbleGamepadTriggers`
- **Escape** — quit
