# input_keyboard

**Target:** `example_input_keyboard`  
**Feature:** Raw keyboard state queries

ImGui panel shows down / just-pressed / just-released / handled state for common keys, plus a list of edge events detected this frame.

## Assets

None.

## Controls

- **WASD, Space, Shift** — watched keys
- **Escape** — quit
