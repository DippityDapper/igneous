# camera

**Target:** `example_camera`  
**Feature:** Camera pan, zoom, bounds

A colonist sprite stays in world space while the camera moves and zooms.

## Assets

- `assets/sprite-sheets/colonist_blue_spritesheet.png` (idle forward column)

## Controls

| Input | Action |
|-------|--------|
| **Arrow keys** | Pan camera |
| **Mouse wheel** | Zoom in/out |
| **Escape** | Quit |
