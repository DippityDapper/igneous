# animation

**Target:** `example_animation`  
**Feature:** Animation, spritesheet atlases

Uses the 8×4 colonist spritesheet. Each row is a directional idle/walk animation; each column is a frame.

## Assets

- `assets/sprite-sheets/colonist_blue_spritesheet.png`

## Controls

| Input | Action |
|-------|--------|
| **W A S D** | Face direction (idle) |
| **Shift + WASD** | Walk animation |
| **Escape** | Quit |

## Spritesheet rows

0 idle down · 1 idle right · 2 idle left · 3 idle up · 4 walk down · 5 walk right · 6 walk left · 7 walk up
