# input_mouse

**Target:** `example_input_mouse`  
**Feature:** Mouse position, velocity, wheel, and button state

Move the mouse to read screen position and velocity. Hold left button to drag a marker. Scroll the wheel to move the marker vertically.

## Assets

None.

## Controls

- **Mouse** — position, velocity, wheel delta
- **Left / right / middle button** — button state
- **Escape** — quit
